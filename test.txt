  ## Conventions strictes (rappel — détails dans MEMORY.md)                                                                                                                                   
  - 1 fichier styles.module.css co-localisé par composant                                                                                                                                     
  - `@reference "<chemin vers src/index.css>"` en première ligne (Tailwind v4)                                                                                                                
  - Classes camelCase                                                                                                                                                                         
  - Hiérarchie via `composes` (base + variantes) plutôt que classes fourre-tout                                                                                                               
  - Aucune chaîne Tailwind ne doit rester dans le JSX (sauf cas extrême type `className={dyn}`)                                                                                               
  - Aucune couleur hardcodée — toujours var(--color-...) ou tokens du projet                                                                                                                  
  - Pour `group-hover` Tailwind, utiliser sélecteur CSS natif `.parent:hover .child`                                                                                                          
  - Si un pattern apparaît sur 3+ composants : extraire dans src/styles/shared.module.css
